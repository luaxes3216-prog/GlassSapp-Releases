# GlassSapp

Mashiro’s glass-style Windows desktop suite: file tools, desktop widgets, mail, notes, tasks, terminal and more.

## Download

Download **GlassSapp-Windows.zip** from the [latest release](https://github.com/luaxes3216-prog/GlassSapp-Releases/releases/latest). Close GlassSapp from its tray, extract the entire ZIP, then run **Start.cmd**. Requires Windows with .NET Framework 4.8.

## Updates

Starting with 4.3.1, use **Home → Check updates**. No GitHub account or token is required. Updates preserve your settings.

If you have 4.3.0 and cannot access its private update location, install the latest public version once using Start.cmd.

This repository contains official downloads and release notes only. Application source is maintained privately. Public access permits downloads, not changes to official releases.
